# sandie.app

Website and stats portal for Sandie — Track Beers. Track Rips. Track Scores. Get Paid.

- `index.html` — landing page
- `portal.html` — sign in to see your stats (same Supabase backend as the app)

The app itself lives in the `tiger5` repo and is served at https://app.sandie.app.
Hosted on GitHub Pages; `CNAME` sets the custom domain.
